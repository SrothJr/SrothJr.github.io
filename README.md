## 💻 About This Portfolio Project

This repository hosts the source code for my personal portfolio website, published at **[SrothJr.github.io](https://SrothJr.github.io)**.

### Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Routing**: [TanStack Router](https://tanstack.com/router) (file-based routing)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **UI Components**: [Radix UI primitives](https://www.radix-ui.com/)
- **Hosting & CI/CD**: [GitHub Pages](https://pages.github.com/) via [GitHub Actions](https://github.com/features/actions)

### Features

- ⚡ **Blazing Fast**: Vite-powered client-side architecture with optimized assets.
- 🎨 **Dark / Light Mode**: Built-in system-aware theme provider.
- 📄 **Dual CV & Resume Download**:
  - One-click download for **Single-Page Resume** (`Md-Nazim-Hossain_Resume.pdf`).
  - One-click download for **Multi-Page Detailed CV** (`Md-Nazim-Hossain_CV.pdf`).
- 📱 **Fully Responsive**: Mobile-first layout with smooth slide-over navigation.
- 🖼️ **Photography Gallery**: Dedicated photography portfolio highlighting travel, portraits, and street photography.
- 🤖 **Automated CI/CD**: Pushing to `main` automatically triggers the GitHub Actions workflow to build and deploy to GitHub Pages.

## ⚙️ Local Development

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `bun`

### Setup Steps

1. **Clone the repository**:
   ```bash
   git clone https://github.com/SrothJr/SrothJr.github.io.git
   cd SrothJr.github.io
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Preview production build locally**:
   ```bash
   npm run preview
   ```

## 🚢 Deployment (GitHub Pages)

This site is automatically deployed to **GitHub Pages** using GitHub Actions whenever you push to the `main` branch.

The workflow file is located at [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml):
1. Checks out the code.
2. Sets up Node.js and installs dependencies.
3. Compiles TypeScript and runs `vite build`.
4. Uploads the `dist/` directory as an artifact.
5. Deploys to GitHub Pages at **https://SrothJr.github.io**.
